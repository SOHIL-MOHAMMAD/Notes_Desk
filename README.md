# 📝 Notes Desk

> A modern, feature-rich, and lightning-fast note-taking web application built with a striking **neo-brutalist** design aesthetic, smooth micro-interactions, and secure cookie-based authentication.

---

## 🎨 Design & UI Philosophy

**Notes Desk** embraces the **Neo-Brutalism** design trend featuring:
- 🔲 **Bold Borders & Shadows:** Heavy black borders and hard drop shadows (`shadow-[6px_6px_0px_0px_rgba(0,0,0,1)]`) for high-contrast visual hierarchy.
- ✨ **Fluid Micro-Interactions:** Powered by `motion` (Framer Motion) for interactive scaling, rotating, and hover feedback.
- 🍊 **Vibrant Color Palettes:** Energetic background hues combined with crisp typography.

---

## ✨ Features

- **🔐 Secure User Authentication:** Complete sign-up and sign-in functionality with persistent token management via HTTP/secure-cookie handling.
- **📝 CRUD Operations:** Create, read, edit, and delete notes dynamically.
- **⚡ Next.js App Router:** Built on modern Next.js features for optimized server/client component rendering.
- **📱 Fully Responsive:** Clean layout scaling seamlessly from mobile devices to large desktop screens.
- **🛡️ Form Validation & Error States:** Dynamic feedback during loading, error handling for invalid credentials, and disabled states to prevent double submissions.

---

## 🛠️ Tech Stack

- **Frontend:** [Next.js](https://nextjs.org/) (App Router), [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Motion](https://motion.dev/) (Framer Motion)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Backend API:** External REST API hosted on Render (`https://notes-backend-uvim.onrender.com`)
